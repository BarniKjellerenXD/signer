With an App Store Connect API key the server creates the certificate, the wildcard App ID and the ad hoc profile for you, and adds new iPhones automatically.

  1. Open App Store Connect → Users and Access → Integrations → App Store Connect API. The first time, click Request Access and accept.
  2. Team Keys → Generate API Key: name it "{{ site }}", Access Admin.
  3. Download the AuthKey_XXXXXXXXXX.p8 file (Apple only lets you download it once), and copy the Issuer ID (top of the page) and the Key ID.
